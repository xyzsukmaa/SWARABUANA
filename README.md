# Proyek Website Pelestarian Lingkungan & Edukasi SDG
---

## Fungsi Website
* **Identifikasi Tanaman (AI Image Recognition):** Pengguna dapat mengambil foto secara langsung dengan kamera atau mengunggah gambar tanaman untuk mendeteksi, menganalisis, dan mengidentifikasi spesies tanaman secara otomatis beserta detail informasinya.
* **Visualisasi Data Perubahan Iklim & Deforestasi:** Menampilkan grafik visual terkait laju hilangnya pohon/hutan dan penurunan kapasitas penyerapan karbon bumi.
* **Portal Edukasi Lingkungan Gratis:** Menyediakan platform materi pembelajaran terbuka (*open access*) seputar isu lingkungan dan keanekaragaman hayati.
* **Manajemen Konten (Admin):** Modul untuk mengelola entitas data tanaman, statistik deforestasi, serta pembaruan artikel edukasi.

---

## Tujuan (SDG Alignment)
Proyek website ini dibangun untuk mendukung pencapaian **Sustainable Development Goals (SDGs)**:

1. **SDG 15: Ekosistem Daratan (Life on Land)**
   * Memetakan, melindungi, dan melestarikan spesies tanaman lokal serta mencegah hilangnya keanekaragaman hayati.
2. **SDG 13: Penanganan Perubahan Iklim (Climate Action)**
   * Memberikan informasi visual mengenai laju hilangnya pohon/hutan sebagai penyerap karbon bumi.
3. **SDG 4: Pendidikan Berkualitas (Quality Education)**
   * Menyediakan media edukasi lingkungan interaktif yang dapat diakses secara gratis oleh pelajar dan masyarakat umum.

---

## Target Pengguna
* **Pelajar & Mahasiswa:** Membutuhkan akses edukasi lingkungan gratis dan fitur identifikasi instan untuk pembelajaran atau praktik lapangan.
* **Masyarakat Umum:** Pengguna yang ingin mengenali jenis tanaman di sekitarnya menggunakan kamera HP dan meningkatkan kesadaran konservasi.
* **Komunitas / Peneliti Lingkungan:** Membutuhkan alat bantu identifikasi cepat dan referensi pemetaan keanekaragaman hayati lokal.
